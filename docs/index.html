A theme family for focused development.

Three calm palettes for VS Code: warm Dark, cool Dusk and daylight Light. Functions, types, parameters and properties each get a color of their own, ordinary variables stay quiet, and the whole interface matches.

Install in VS Code View on the Marketplace

Free and open source, version 0.2.0. Also for Cursor, Windsurf and VSCodium via Open VSX.

Theme

Every color has a job

Aureon uses VS Code's semantic highlighting, so a symbol is colored by what it is, not just where it sits. A function looks the same where it's declared and where it's called. Related roles share a hue, and anything that shows up on most lines stays neutral.

TypeScript and JavaScript get this out of the box. Other languages use carefully scoped grammar colors.

  • Functions and methods getIconSets() Declared or called, one color
  • Classes, types and enums class Circle The shape of your data
  • Interfaces and type parameters Shape<T> A lighter step of the type color
  • Parameters radius Italic, so inputs stand out
  • Properties this.colors Members, keys and fields
  • Enum members and literals Level.High Numbers, booleans, constants
  • Keywords export async Structure, italic
  • Strings "Choose a set" Text and data
  • Variables const items Neutral on purpose
  • Comments // why, not what Quiet, italic

Install

  1. VS Code. Use Install in VS Code, or search for Aureon in the Extensions view.
  2. Cursor, Windsurf, VSCodium. Search for Aureon in the extensions view, or get it from Open VSX.
  3. Press Ctrl+K Ctrl+T (Cmd on macOS) and choose an Aureon theme.

Each palette also comes as a Vivid version with a solid accent status bar, and a No Italics version for fonts without a good italic.

{
