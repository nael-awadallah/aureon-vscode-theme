A theme family for focused development.

Three calm palettes for VS Code: warm Dark, cool Dusk and daylight Light. Functions, types, variables and parameters each get a color of their own, control flow stands apart, and the whole interface matches.

Theme

Every color has a job

Aureon uses VS Code's semantic highlighting, so a symbol is colored by what it is, not just where it sits. A function looks the same where it's declared and where it's called. Each kind of symbol has its own hue, following the structure of VS Code's 2026 themes, while operators and punctuation stay quiet.

TypeScript and JavaScript get this out of the box. Other languages use carefully scoped grammar colors.

Install

  1. VS Code. Use Install in VS Code, or search for Aureon in the Extensions view.
  2. Cursor, Windsurf, VSCodium. Search for Aureon in the extensions view, or get it from Open VSX.
  3. Press Ctrl+K Ctrl+T (Cmd on macOS) and choose an Aureon theme.

Each palette also comes as a Vivid version with a solid accent status bar, and a No Italics version for fonts without a good italic.
